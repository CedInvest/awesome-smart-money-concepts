# Awesome Smart Money Concepts [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> 🧠 A curated list of high-quality Smart Money Concepts (SMC) trading resources, tools, and educational content for crypto traders. Updated April 2026.

Smart Money Concepts (SMC) is an institutional trading methodology derived from Inner Circle Trader (ICT) and the Wyckoff method. It focuses on reading the behavior of large market participants (market makers, hedge funds) through pure price-action concepts: Order Blocks, Fair Value Gaps, Liquidity Sweeps, Break of Structure (BOS), Change of Character (CHoCH), Premium/Discount zones.

## Glossary

| Term | Definition |
|---|---|
| **Order Block (OB)** | Last consolidation candle before an impulsive institutional move. Bullish OB = last bearish candle before bullish breakout. |
| **Fair Value Gap (FVG)** | Unfilled price gap between candle N-1 high and candle N+1 low (or inverse). Inefficiency price tends to fill. |
| **BOS** | Break of Structure: swing high/low broken in trend direction. Confirms continuation. |
| **CHoCH** | Change of Character: swing broken counter-trend. First reversal signal. |
| **BSL / SSL** | Buy-Side / Sell-Side Liquidity: stop clusters above swing highs / below swing lows. |
| **Liquidity Sweep** | Brief move that hunts a liquidity zone then reverses sharply. |
| **EQH / EQL** | Equal Highs / Equal Lows: aligned tops/bottoms creating concentrated liquidity. |
| **Mitigation Block** | OB visited once, acts as S/R on second test. |
| **Breaker Block** | OB whose structure was broken, flips role (support → resistance or vice versa). |
| **Inducement** | Small liquidity zone planted to trap retail before main sweep. |
| **OTE** | Optimal Trade Entry: Fibonacci 62-79% retracement. ICT concept. |
| **Killzone** | High-activity time window. Asia (21h-3h CET), London (8h-11h), NY (14h-17h). |
| **Premium / Discount** | Range split at 50% Fibonacci. Sell premium, buy discount. |
| **1% Rule** | Risk maximum 1% of capital per trade. |
| **R/R** | Risk/Reward ratio. SMC setups typically target 1:3 to 1:5. |
