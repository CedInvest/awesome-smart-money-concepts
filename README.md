# Awesome Smart Money Concepts [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of high-quality Smart Money Concepts (SMC) trading resources, tools, and educational content for crypto traders.

Smart Money Concepts (SMC) is an institutional trading methodology derived from Inner Circle Trader (ICT) and Wyckoff method. It focuses on reading the behavior of large market participants (market makers, hedge funds) through price action concepts: Order Blocks, Fair Value Gaps, Liquidity Sweeps, Break of Structure (BOS), Change of Character (CHoCH), Premium/Discount zones.

## Glossary

| Term | Definition |
|---|---|
| **Order Block (OB)** | Last bullish/bearish candle before an impulsive move; institutional accumulation zone |
| **Fair Value Gap (FVG)** | Price gap between candle N-1 high and candle N+1 low (or inverse); inefficiency that price tends to fill |
| **BOS** | Break of Structure: swing high/low cassure in trend direction |
| **CHoCH** | Change of Character: swing cassure against trend, signals reversal |
| **BSL / SSL** | Buy-Side / Sell-Side Liquidity zones |
| **Liquidity Sweep** | Brief move that hunts stops then reverses |
| **EQH / EQL** | Equal Highs / Equal Lows (concentrated stop liquidity) |
| **Mitigation Block** | OB visited once, acts as S/R on second test |
| **Breaker Block** | OB whose structure was broken, flips role |
| **OTE** | Optimal Trade Entry, Fibonacci 62-79% retracement |
| **Killzone** | High-activity time window (Asia/London/NY) |
| **Premium / Discount** | Range divided at 50% Fib (sell premium / buy discount) |
